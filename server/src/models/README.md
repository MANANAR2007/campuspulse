# Models Directory

This directory is reserved for Mongoose / Database models in upcoming stages.
Planned models for CampusPulse:
- `User.js` (Student & Admin schemas, auth credentials, campus roles)
- `Issue.js` (Title, description, category, severity, location, status, author, alertRequest, affectedUsers)
- `Notification.js` (Target user, event type, message, read status, reference issue)
- `Comment.js` (Issue reference, author, message, timestamp)
